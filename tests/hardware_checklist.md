## 故障排查指引

### 通用检查流程

```
问题出现
    │
    ▼
电源检查 → 万用表测 5V/3.3V 供电
    │
    ▼
串口日志 → 打开 115200 串口监视器查看错误信息
    │
    ▼
I2C 扫描 → 确认 OLED(0x3C) 和 PAJ7620(0x73) 都在
    │
    ▼
UART 检查 → 确认雷达 256000 波特率通信正常
    │
    ▼
逐个模块 → 从 Phase 1 开始逐个验证直到发现故障点
```

### 常见问题速查表

| 现象 | 可能原因 | 解决方案 |
|------|----------|----------|
| 完全无反应 | 电源问题 | 检查 USB 供电，测量 3.3V 输出 |
| LED 不闪 | GPIO48 复用冲突 | 检查是否被其他外设占用 |
| 串口无输出 | 驱动问题 | 重新安装 USB 驱动 |
| OLED 不亮 | I2C 地址错误 | 用 I2C 扫描确认地址 |
| 雷达无数据 | 接线错误 | TX→RX 交叉，检查波特率 |
| 状态机不跳 | 距离阈值不对 | 调整 config.h 中的距离值 |
| PC 连不上 | 端口不对 | 查看设备管理器/列表 |
| 遮罩不显示 | PyQt6 未安装 | pip install PyQt6 |
| 手势不识别 | 距离太远 | 手在 5~15cm 范围内操作 |

### 调试技巧

1. **启用详细日志**：`config.yaml` 中设置 `level: "DEBUG"`
2. **使用串口模拟器**：`python tests/serial_simulator.py` 测试 PC 端（无需硬件）
3. **LED 诊断码**：可添加 LED 闪烁模式表示错误码（1闪→I2C错误，2闪→雷达错误...）
4. **OLED 调试**：OLED 可显示内部状态变量的实时值
5. **示波器**：检查 I2C 和 UART 信号质量
