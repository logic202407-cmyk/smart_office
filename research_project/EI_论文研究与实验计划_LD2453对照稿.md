# EI 论文研究与实验计划 · LD2453 对照稿

> 本文件是 `EI_论文研究与实验计划.md` 的 LD2453 方向对照稿，供后续取舍和合并；不覆盖原计划，不修改固件、PC 客户端、采集脚本或到货测试执行单。
>
> 本稿与 `ld2453_ei_预注册研究协议.md` 对齐：所有性能阈值均为待实采校准的初值，不作为实验结果；论文只讨论“空间风险 / 多目标可分离性 / 端侧响应”，不声称识别身份、真实攻击行为或“偷窥意图”。

---

## 1. 论文定位

**暂定题目**：面向开放办公屏幕隐私的非视觉空间风险评估：基于低成本 24 GHz 多目标毫米波雷达的可证伪验证。

**一句话贡献**：在不使用部署端摄像头/音频的前提下，验证低成本多目标毫米波雷达能否把屏幕隐私保护从“单人距离阈值触发”推进到“多人空间关系 + 停留时间 + 端侧响应”的风险判定。

**论文主张层级**：

1. **主科学问题**：LD2453 的多目标 x/y 输出能否在开放办公几何中可靠地区分“仅使用者”与“使用者 + 身后/侧后方第二人”。
2. **方法问题**：在多目标输出不保证稳定 ID 的条件下，主目标选择、集合匹配、短窗口滤波与状态保持能否减少误报、漏报和抖动。
3. **系统验证**：雷达风险状态能否以可接受延迟驱动 PC 端遮罩/告警/锁屏等隐私动作。

**不可作为论文主张的内容**：

- 不识别身份。
- 不识别真实攻击者或主观“偷窥意图”。
- 不做屏幕内容重建。
- 不把厂商“最多 3 目标”当作可靠三目标实验结果。
- 不把 `pixel_distance_mm` 当作目标真实径向距离；空间判定只使用 `x_mm` / `y_mm`。

---

## 2. 研究问题

**RQ1 多目标空间可分离性**：在正后方径向对齐和侧后方横向分离场景中，LD2453 能否以可量化指标区分“仅使用者”与“使用者 + 第二人”，并优于 LD2410B 负对照？

**RQ2 多目标风险判定算法**：在 LD2453 输出至多 3 个目标且 `slot` 不保证跨帧身份稳定的条件下，主目标选择、集合匹配、短窗口滤波与状态保持分别对误报、漏报、触发延迟和状态抖动有什么影响？

**RQ3 非视觉端侧响应**：在不采集部署端图像/音频的前提下，雷达空间风险状态能否稳定驱动 PC 端隐私动作，并形成可审计的端到端时间线？

## 3. 现有可用基础

- 已有 ESP32-S3、LD2410B、OLED、PAJ7620U2 与 USB CDC/PC 端联动原型，可作为旧传感器和端侧响应基础。
- 已有 LD2410B 串口/遥测采集路径与 JSONL + metadata 记录习惯，可迁移为 LD2453 数据治理规范。
- `tools/ld2453_reader.ps1` / `tools/ld2453_reader.py` 已有独立 LD2453 解析器路线；协议层自测和实采上电校验需分开表述。
- 已产出 `ld2453_到货测试执行单_修订建议.md`、`ld2453_reader_字段与元数据清单.md`、`ld2453_ei_预注册研究协议.md`，可作为实验冻结前文档基础。

**当前不能作为结果的内容**：

- LD2453 多目标可分离性尚未实采验证。
- UP-R 正后方径向两人分离能力未知。
- 任何准确率、误报率、响应延迟、长时运行结论都必须等正式采集和分析后才能写入结果。

## 4. 冻结与一致性要求

正式实验前必须冻结：

1. LD2453 官方手册与串口协议版本、归档路径和核验记录。
2. `ld2453_parser_validation.md`：包括 30 字节帧、尾 `55 CC`、`targets` 长度、x/y 符号和量纲、解析异常计数。
3. 固件、PC 客户端、采集脚本、分析脚本的 Git commit 或版本标签。
4. 安装几何：雷达高度、横向偏移、俯仰角、显示器位置、地面网格、非金属支架、照片编号。
5. 试次矩阵、主/次指标、PASS/REVISE/NO-GO 门槛、剔除规则。
6. 主目标选择规则、目标集合匹配规则、状态机参数。
7. 离线视频真值标注规则、时钟锚点同步方法、伦理/知情同意与数据保留方案。

任何正式实验后的阈值变更都必须标记为探索性分析，不进入预注册主结果。

## 5. 对照方法与消融设计

| 编号 | 方法 | 传感器 | 用途 |
|---|---|---|---|
| B0 | LD2410B `detect_distance` + 单阈值 | LD2410B | 旧传感器负对照；验证升级动机 |
| B1 | 最近目标代理 + 单阈值 | LD2453 | LD2453 的最低可用基线 |
| B2 | B1 + 主目标选择规则 | LD2453 | 衡量“谁是使用者/近屏目标”的选择贡献 |
| B3 | B2 + 短窗口滤波 | LD2453 | 衡量滤波对误报、漏报和抖动的影响 |
| B4 | B3 + 停留时间/状态保持 | LD2453 | 完整空间风险判定方法 |

**约束**：

- B1-B4 使用同一批 LD2453 原始数据离线复算，避免采集差异影响算法比较。
- B0 使用同一安装几何和相同试次序列复跑，作为负对照；不得把不同房间、不同距离、不同干扰条件下的数据直接比较。
- `slot` 只表示帧内槽位，不表示跨帧同一人；如需轨迹指标，必须显式使用集合匹配或目标关联算法。

## 6. 实验矩阵

### 6.1 LD2453 到货 pilot

| 条件 | 场景 | 目的 |
|---|---|---|
| 通讯自检 | 30 s 实采 | 验证帧长、尾、目标数范围、解析异常计数 |
| 单目标已知位置 | 1.0 m 或可测距离静止 | 验证 x/y 符号、量纲和字段解释 |
| E0-A | 纯净空场 | 空场误报基线 |
| U1 | 一人坐终端前 | 主目标位置与稳定性 |
| UP-R-1.0 | 正后方径向对齐两人 | 关键通过项 |

pilot 只用于检查流程和校准初值，不作为论文主结果。

### 6.2 正式多目标空间实验

| 条件 | 场景 | 主判定 |
|---|---|---|
| E0-A | 纯净空场 | 空场误报率 |
| E0-B | 空场 + 风扇/窗帘/可动椅 | 干扰伪目标率 |
| U1 | 一人坐终端前 | 单人存在、主目标位置误差 |
| UP-R-0.5 | 使用者 + 正后方第二人，间距 0.5 m | 径向难例 |
| UP-R-1.0 | 使用者 + 正后方第二人，间距 1.0 m | 径向关键通过项 |
| UP-L-0.5 | 使用者 + 侧后方第二人，横向 0.5 m | 横向难例 |
| UP-L-1.0 | 使用者 + 侧后方第二人，横向 1.0 m | 横向通过项 |
| UP2 | 第二人走入、停住、离开 | 事件时序解释性 |
| NEG | LD2410B 同场景复跑 | 负对照 |

### 6.3 端到端响应与稳定性

- 记录人工事件起点、雷达首帧、风险状态变化、串口发送、PC 端动作显示时间。
- 报告 median / P95 / max 延迟，而不只报告平均值。
- 连续运行测试记录供电、日志完整性、重启、异常、内存或串口断链；不得只写“未死机”。

## 7. 指标与统计

| 目标 | 主指标 | 报告方式 |
|---|---|---|
| 通讯可靠性 | 解析异常计数、坏帧率、目标数分布 | trial-level 摘要 |
| 多目标分离 | UP-R/UP-L 两目标帧比例、目标计数 MAE | Wilson 95% CI、同场景配对比较 |
| 空间位置 | x/y MAE、RMSE、Bias | 分距离/方位/姿态箱线图 |
| 多目标跟踪 | MOTA/MOTP 或集合匹配误差 | 若关联不稳定则降级报告 |
| 风险事件 | Precision、Recall、F1、FP/小时、漏报率 | 事件级混淆矩阵、CI、效应量 |
| 状态稳定性 | 无意义状态切换/小时、恢复时间 | B1-B4 消融对比 |
| 端到端响应 | median、P95、max 延迟 | 分阶段瀑布图或 CDF |
| 长时运行 | 日志完整率、异常次数、重启次数 | 运行时间线 |

**统计规则**：

- 二元/比例指标使用 Wilson 95% CI。
- 多重比较使用 Benjamini-Hochberg FDR。
- 样本量不能用“每条件 30 次”直接背书；需补功效或 CI 精度论证。
- 参与者、位置、试次批次作为随机因子或分层变量。
- 视频真值抽样标注需报告 Fleiss' kappa；一致性不足时先修订标注指南。

## 8. 论文结构建议

1. **引言**：开放办公屏幕隐私风险；摄像头/眼动方案的隐私与部署代价；雷达非视觉空间感知的机会与限制。
2. **相关工作**：肩窥/屏幕隐私保护、proxemics sensing、毫米波人体存在与多目标跟踪、传感器评测方法与标准缺口。
3. **问题定义**：把“偷窥意图”降格为可测的“空间风险事件”；定义风险区、停留时间、多人邻近与不做身份/意图推断的边界。
4. **系统与数据流**：LD2453/LD2410B、ESP32、PC 端响应、日志与元数据；说明 `pixel_distance_mm` 不用于空间判定。
5. **方法**：目标集合处理、主目标选择、短窗口滤波、状态保持、风险事件输出；说明 `slot` 非身份 ID。
6. **实验设计**：预注册矩阵、真值位置、时钟锚点、负对照、消融、统计计划、伦理处理。
7. **结果**：先报告通讯与上电校验，再报告多目标分离、负对照、消融、端到端延迟、失败案例。
8. **讨论**：正后方径向分离极限、静止人脱落、风扇/窗帘误报、遮挡/聚类、多雷达或更高频方案的未来工作。
9. **结论**：只总结实验证据支持的空间风险能力，不扩展到意图或身份。

## 11. 与原计划的差异

| 原计划 | 本对照稿 |
|---|---|
| 主线是 LD2410B 单目标距离/状态机 | 主线是 LD2453 多目标空间关系验证 |
| B0-B3 均是单目标语义 | B0 为 LD2410B 负对照，B1-B4 为 LD2453 消融 |
| RQ 未显式覆盖多人分离 | RQ1 将 UP-R/UP-L 多目标可分离性置于主问题 |
| 指标缺多目标/关联指标 | 增加计数误差、MOTA/MOTP 或集合匹配误差 |
| “每条件 30 次”是操作要求 | 明确 30 次不是统计保证，需功效或 CI 精度论证 |
| 端侧响应是系统功能 | 端侧响应降为系统验证，不压过科学问题 |

## 12. 当前建议

优先级应为：

1. LD2453 到货后先做 `ld2453_parser_validation.md`。
2. 跑 pilot：通讯自检、单目标已知位置、E0-A、U1、UP-R-1.0。
3. 若 UP-R-1.0 失败，先 REVISE 安装几何和阈值初值；连续失败则 NO-GO，不进入 V2 PCB 打样。
4. 若 pilot 可解释，再冻结正式实验协议和分析脚本。
5. 正式实验后再把本对照稿合并进投稿大纲。
