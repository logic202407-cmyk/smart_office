# LD2453 V2 终端隐私风险感知节点：硬件架构

## 设计目标

做一个可固定在公共终端显示器侧上方的低成本、非视觉传感器节点。LD2453 是唯一板载雷达；不保留与板载雷达并联的第二颗雷达。

## 功能框图

```text
USB-C 5V
   |
保护与稳压 ---- 3.3V 雷达专用滤波 ---- LD2453
   |                                      |
   +--------------- 3.3V ---------------- ESP32-S3 ---- Wi-Fi JSONL/TCP
                                          |       |
                                      USB 调试   OLED/状态灯
```

## 必须冻结的接口

| 功能 | V2 需求 |
|---|---|
| 雷达供电 | 3.3 V；在雷达支路放置独立去耦与滤波；禁止将 5V 直接接入 LD2453 |
| 雷达数据 | 独占 ESP32 UART，TX/RX 交叉连接；预留 GND、TX、RX、3.3V 测试点 |
| 调试 | USB-C 串口；保留 EN 与 BOOT |
| 扩展 | 独立的外接 UART，不与 LD2453 总线并联 |
| 记录 | Wi-Fi TCP/JSONL 与本地串口同时可用 |

## 机械与射频约束

- LD2453 位于 PCB 边缘，天线面前保持无遮挡；壳体前方使用非金属、对 24 GHz 友好的材料。
- 不让金属显示器支架、电源线或 PCB 大面积金属结构位于天线正前方。
- 传感器节点采用可调角度的显示器侧上方夹具；正式安装高度、偏移和俯仰角由到货测试冻结。
- 传感器节点必须刚性固定；自身振动不能成为运动目标来源。

## 不在本轮固定的内容

- 最终 PCB 外形、天线周围铜皮禁布范围、屏蔽背板尺寸；这些需以 LD2453 实物、官方封装/天线罩指南和安装试验共同冻结。
- 风险区边界与告警阈值；它们必须来自屏幕可读性实验和带真值的雷达数据，而不是产品手册。
