## 1. 论文定位

**暂定题目**：面向开放办公屏幕隐私的非视觉空间风险评估：基于低成本 24 GHz 多目标毫米波雷达的可证伪验证。

**主线**：从 LD2410B 单目标距离/状态机，升级为 LD2453 多目标空间关系验证。论文主贡献是“多人空间风险判定是否可行”，端侧响应是系统验证。

**不可越界**：

- 不识别偷窥意图。
- 不识别身份。
- 不重建屏幕内容。
- 不把厂商参数写成实验结果。
- 不把 `pixel_distance_mm` 当真实径向距离。

## 2. RQ

| 编号 | 研究问题 |
|---|---|
| RQ1 | 基于 LD2453 多目标的时序风险判定，能否比单阈值更准确、稳定地识别近距离持续接近事件？ |
| RQ2 | LD2453 在正后方径向对齐与侧后方横向分离两种几何下，能否以可量化精度区分“仅使用者”与“使用者 + 身后人”？ |
| RQ3 | 目标关联 + 主目标选择对风险判定精度有多大贡献？ |
| RQ4 | 短窗口滤波与状态保持分别对误报、漏报、延迟和抖动有什么影响？ |
| RQ5 | 系统在不采集部署端图像/音频的前提下，能否以可接受延迟驱动 PC 端隐私动作？ |

## 3. 基线与消融

| 编号 | 方法 | 传感器 | 论文用途 |
|---|---|---|---|
| B0 | LD2410B `detect_distance` + 单阈值 | LD2410B | 旧传感器参考 / 负对照锚点 |
| B1 | LD2453 最近目标 y + 单阈值 | LD2453 | LD2453 数据源最低基线 |
| B2 | B1 + 主目标选择规则 | LD2453 | 衡量“从 <=3 目标中选使用者”的贡献 |
| B3 | B2 + 短窗口滤波 | LD2453 | 衡量滤波贡献 |
| B4 | B3 + 停留时间/状态保持 | LD2453 | 完整方法 |

原则：

- B1-B4 使用同一批 LD2453 原始数据离线复算。
- B0 必须同安装、同场景、同时间窗复跑。
- 主目标选择规则采集前冻结，不做数据驱动挑选。
- `slot` 不是跨帧身份；轨迹指标必须来自显式关联或集合匹配。

## 4. 指标表

| 目标 | 主要指标 | 报告方式 |
|---|---|---|
| 通讯可靠性 | 坏帧率、parse_errors、目标数分布 | trial-level 摘要 |
| 目标存在检测 | Precision、Recall、F1、Specificity | 95% CI、混淆矩阵 |
| 多目标分离 | >=2 目标帧占比、计数误差、MOTA/MOTP 或集合匹配误差、两目标 x/y 差 MAE | 分 UP-R/UP-L 与 0.5/1.0 m 档报告 |
| 主目标选择 | 主目标=使用者识别正确率、ID 切换/碎片数或关联失败率 | B2 vs B1 配对 |
| 风险事件判定 | 事件级 Precision、Recall、F1、FP/小时、漏报率 | B0-B4 对比 |
| 距离/位置估计 | x/y MAE、RMSE、Bias、SD | 分距离/姿态/场景箱线图 |
| 时延 | median、P95、max | CDF 或分阶段瀑布图 |
| 状态稳定性 | 状态切换/小时、恢复时间 | B3/B4 消融 |
| 长时运行 | 可用率、异常/重启、日志丢失率 | 运行时间线 |

统计口径：

- Wilson 95% CI。
- 配对比较 + 效应量。
- FDR 控制多重比较。
- 每条件 30 次不是保证；需功效或 CI 精度论证。
- 参与者、位置、试次作为随机因子。
- 真值标注报告 Fleiss' kappa。

## 5. 方法章节结构

论文第 3 节建议从“单目标距离选择”改为以下模块：

1. 传感器与坐标系：LD2453/LD2410B、x/y 坐标、`pixel_distance_mm` 边界。
2. 数据流：雷达 -> ESP32/采集器 -> PC 响应 -> JSONL/metadata。
3. 目标集合处理：帧内目标集合、可解释目标、离群规则。
4. 目标关联与主目标选择：集合匹配或 N 人计数保守输出；主目标规则冻结。
5. 时序风险判定：风险距离、停留时间、短窗口滤波、状态保持。
6. 端侧响应：遮罩/告警/锁屏动作与时间戳链路。

## 6. 实验章节结构

1. P1 通讯与 parser validation。
2. 单目标已知位置 x/y 校验。
3. E0-A/E0-B 空场与干扰。
4. U1 单人主目标。
5. UP-R 正后方径向两人，0.5/1.0 m。
6. UP-L 侧后方横向两人，0.5/1.0 m。
7. UP2 动态走入、停住、离开。
8. NEG：LD2410B 同场景负对照。
9. B1-B4 离线消融。
10. 端到端响应与长时稳定。
