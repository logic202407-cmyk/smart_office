# 数据字典与处理规则（主目标选择 + 离群/缺失）

> 用途：把 JSONL 各记录类型、派生字段、主目标选择规则、离群/缺失处理**写成可执行、预注册冻结**的规范，供分析脚本与复现使用。
> 边界：只定义“空间风险”相关字段与规则，不含身份/意图。空间位置只用 x/y；`pixel_distance_mm` 仅记录。

---

## 1. 原始记录字段字典（按 type 分类）

### 1.1 LD2453 目标帧（`type=ld2453_targets`）

| 字段 | 类型 | 语义 | 用途 |
|---|---|---|---|
| `type` | str | `ld2453_targets` | 分派 |
| `t_ms` | int | 采集端本地单调 ms | 时序 |
| `targets` | list | 帧内目标数组（0–3 个） | 核心 |
| `raw_hex` | str | 原始 30 字节十六进制 | 追溯/校验 |
| `targets[].slot` | int | 帧内槽位 1–3 | **仅帧内标识，不作跨帧 ID** |
| `targets[].x_mm` | int | 横向坐标（符号-幅值） | 空间位置（横向） |
| `targets[].y_mm` | int | 纵向坐标（符号-幅值） | 空间位置（径向，真实距离判据） |
| `targets[].speed_cm_s` | int | 径向速度（符号-幅值） | 趋势参考 |
| `targets[].pixel_distance_mm` | int | 手册 “pixel distance value / distance sampling length” | **仅记录，不当真实距离** |

### 1.2 既有状态帧（`type=state`，LD2410B 对照用）

`t_ms, frames, present, radar_state, target_state, state, distance_cm, raw_distance_cm, avg_distance_cm, display_distance_cm, trend, hold_ms, state_hold_ms, downgrade_hold_ms, moving_distance_cm, moving_energy, static_distance_cm, static_energy, detect_distance_cm, age_ms, gesture, gesture_age_ms`

### 1.3 既有测量帧（`type=measurement`，测距基线用）

`t_ms, frames, present, target_state, direct_distance_mm, direct_distance_cm, moving_distance_mm, moving_energy, static_distance_mm, static_energy, measurement_valid`

### 1.4 工程帧（`type=engineering`）

`t_ms, moving_gate_energy[], static_gate_energy[], light, out`

## 2. 派生字段（分析脚本产出，不写入原始 JSONL）

| 派生字段 | 定义 | 公式/规则 |
|---|---|---|
| `n_targets` | 帧内目标数 | `len(targets)` |
| `main_target` | 主目标（使用者） | 见 §3 主目标选择规则 |
| `main_y_mm` | 主目标径向距离 | `main_target.y_mm` |
| `risk_score` | 空间风险分数 | 距离 + 停留时长 + 多人邻近的确定性函数（见 §4） |
| `event_label` | 帧级/事件级真值标签 | 由离线视频标注独立给出（见标注手册） |
| `anomaly` | 解析/逻辑异常标志 | 帧长≠30、尾≠55 CC、越界等 |

## 3. 主目标（使用者）选择规则（预注册冻结，禁数据驱动挑选）

> 规则必须在采集前选定一个并冻结；若需改，须在冻结记录里说明理由。

**候选规则（择一预注册）**：
- **R-A（最近优先）**：`main_target = argmin(y_mm)`，且 `y_mm>0`；
- **R-B（最近且稳定）**：`main_target = argmin(y_mm)`，且该目标在最近 `N=3` 帧内都存在（帧间以 `y` 最近邻匹配）；
- **R-C（先验区域）**：取落在“就坐者先验区域”（预注册的 x/y 范围框）内的目标中 `y` 最小者。

**伪代码（R-A 为例）**：
```
main_target(frame):
    cands = [t for t in frame.targets if t.y_mm > 0 and in_fov(t)]
    return min(cands, key=lambda t: t.y_mm) if cands else None
```

## 4. 空间风险分数（确定性，可证伪）

```
risk_score(t) =
  base = 1[ main_y_mm <= R_risk ]                       # 进入风险距离
  dwell = 1[ 连续满足 base 的时长 >= T_dwell ]          # 停留
  multi = 1[ n_targets >= 2 且存在第二目标 y 差 <= D_near ]  # 多人邻近
  return {base, dwell, multi}  # 或加权分；权重预注册
```
阈值 `R_risk`、`T_dwell`、`D_near` 在采集前预注册，不由结果反推。

---

## 5. 离群/异常与缺失数据规则（预注册）

1. **帧级异常**：帧长 ≠30 或尾非 `55 CC` → 该帧剔除并计数；若剔除率 > 预注册上限（如 5%）→ 该试次标记 `REVISE`。
2. **目标越界**：`y_mm<=0` 或超出冻结 FOV 范围 → 不计入 `n_targets`/主目标候选。
3. **跳跃离群**：相邻帧主目标 `|Δy|` 超过物理可行阈值（如 1 m/帧）→ 视为关联断裂，按目标关联规则处理，不直接平滑。
4. **断流/掉帧**：`t_ms` 间隔超过预注册阈值（如 500 ms）→ 记录缺口，影响时延/可用率指标按规则处理。
5. **标注缺失**：某事件无真值 → 该事件从对应指标中剔除，并报告剔除数量；不事后补标。
6. **缺失数据处理原则**：预注册（完整案例分析 / 多重插补），不事后切换。

---

## 6. 目标关联约定（不把 slot 当稳定 ID）

- 帧间集合匹配：以 `(x,y)` 欧氏距离做最近邻/匈牙利匹配，距离门预注册（如 0.5 m）。
- 输出两种口径：**轨迹级**（有匹配）与 **计数级**（仅 `n_targets`）。轨迹级用于 MOTA/MOTP；计数级用于“≥2 目标”分离判据。
- 若轨迹级关联质量（ID 切换/碎片）低于预注册阈值 → 论文仅主张“N 人计数”级结论，不主张稳定轨迹。
