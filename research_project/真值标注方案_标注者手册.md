# 真值标注方案 · 标注者手册（草案）

> 用途：规定离线视频如何标注真值、如何计算标注者一致性、如何与雷达时间线对齐。视频仅知情同意下作离线标注，**不含身份**，不进入投稿数据。

---

## 1. 标注对象与字段（每帧或每事件）

| 字段 | 取值 | 说明 |
|---|---|---|
| `person_count` | 0 / 1 / 2 / ≥3 | 画面内可见人数（仅计数） |
| `user_present` | 0 / 1 | 是否有人处于“就坐使用者”位置（真值锚） |
| `observer_present` | 0 / 1 | 是否存在第二人（后方/侧后方） |
| `geometry` | rear / lateral / none | 第二人相对使用者的几何（正后方径向 / 侧向 / 无） |
| `event` | enter / hold / leave / none | 事件类型 |
| `event_start_ms` / `event_end_ms` | int | 相对视频时间轴（换算到墙钟 UTC） |

> **禁止标注**：身份、性别、年龄、面部、表情、是否“偷窥/意图”。任何越界字段都不得记录。

---

## 2. 事件标签规则（预注册，写定）

- **enter**：第二人从风险区外进入风险区（`y ≤ R_risk`）的时刻区间。
- **hold**：第二人停留在风险区内 ≥ `T_dwell` 的区间。
- **leave**：第二人离开风险区的时刻区间。
- 阈值 `R_risk`、`T_dwell` 与风险分数规则一致（见数据字典 §4）。

---

## 3. 时钟同步

1. 采集端在开始/结束打 `clock_anchor`（墙钟 UTC ↔ 本地单调 ms）。
2. 视频在开始录制时对时（拍一下带墙钟的画面，或与采集端同源 NTP）。
3. 标注事件时间戳统一换算到**墙钟 UTC**，再映射回雷达 `t_ms` 时间轴，允许预注册的偏移容差（如 ±100 ms）。

---

## 4. 双标注者流程与一致性

1. 两名标注者**独立**标注同一批样本（预注册抽样比例，如 20% 试次）。
2. 计算 **Fleiss' kappa**（多类别：person_count / event）；二分字段用 Cohen's kappa。
3. 一致性门槛预注册：κ ≥ 0.8 强一致；0.6–0.8 可接受但需报告；< 0.6 需修订规则并重标。
4. 分歧处理：由第三名仲裁者裁定；仲裁结果也记录，用于报告不一致来源。

---

## 5. 标注样本量

- 按 Flack et al. 1988（两标注者 kappa 样本量）与 Donner & Eliasziw 1987 公式，预注册标注片段/帧数，达到期望 kappa 精度（如 CI 宽度 ≤ 0.2）。

---

## 6. 交付物

- 标注文件（CSV/JSONL，含字段与时间戳，无身份）。
- 标注者一致性报告（kappa + CI + 分歧清单）。
- 标注规则版本号（规则变更需记录）。
