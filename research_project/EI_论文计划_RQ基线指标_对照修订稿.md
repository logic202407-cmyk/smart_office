# EI 论文计划 · RQ / 基线 / 指标 对照修订稿

> 本稿对 `EI_论文研究与实验计划.md` 的 **RQ、消融基线、指标表** 三节做**对照修订**，以适配 LD2453 多目标传感器；**不覆盖**原计划文件，供 Codex 决定是否合并。
>
> 修订动因：原计划全部以 LD2410B **单目标**为对象（“主目标距离选择”“三点滤波”“状态机”），未吸收 LD2453 多目标带来的两个真正贡献点——**多目标分离**与**目标关联 + 主目标选择**。
>
> 事实基准：LD2453 手册（Codex 核验，供电 3.0–3.6 V 典型 3.3 V、7×30 mm、~76 mA、256000、三目标、30 字节帧）。主张边界不变：只讲空间风险，不讲意图/身份/内容重建。

## 1. RQ 对照（旧 → 新）

| # | 旧 RQ（原计划） | 修订 RQ |
|---|---|---|
| RQ1 | 时序判定能否比单阈值更准、更稳地识别近距离持续接近事件 | 保留，但主语改为“基于 LD2453 多目标的时序风险判定” |
| RQ2 | 主目标距离选择、短窗口滤波与状态保持分别对误报/漏报/延迟/抖动的影响 | **拆解**：主目标选择在 LD2453 下变为“从 ≤3 目标中选使用者”，需单列（见 RQ3） |
| RQ3 | 无图像/音频前提下能否以可接受延迟驱动 PC 隐私动作 | 保留（端到端） |
| **RQ4（新增）** | — | LD2453 在正后方径向对齐与侧后方横向两种几何下，能否以可量化精度（≥2 目标帧占比、计数误差、MOTA/MOTP、y/x 差 MAE）区分“仅使用者”与“使用者+身后人”？ |
| **RQ5（新增）** | — | 目标关联 + 主目标（使用者）选择对风险判定精度的贡献有多大？ |

## 2. 消融基线对照（旧 → 新）

| # | 旧（原计划） | 修订 | 用途 |
|---|---|---|---|
| B0 | 原始 LD2410B `detect_distance` + 单阈值 | **LD2410B `detect_distance` + 单阈值** | 旧传感器参考 / 负对照锚点（证明升级收益） |
| B1 | 主目标距离选择 + 单阈值 | **LD2453 单目标代理（取最近目标 y）+ 单阈值** | LD2453 数据源基线 |
| B2 | B1 + 三点滤波 | **B1 + 主目标选择规则（从 ≤3 目标选使用者）** | 衡量“主目标选择”贡献 |
| B3 | B2 + 当前状态机/保持逻辑 | **B2 + 短窗滤波** | 衡量滤波贡献 |
| **B4（新增）** | — | **B3 + 状态机/保持逻辑** | 完整方法 |

> 关键语义变化：原 B1 的“主目标距离选择”在 LD2453 下**不再等于**“取最近目标”；二者需分开。**主目标选择规则**必须在采集前冻结（如“y 最小且稳定 N 帧者”或“与就坐者先验区域最近者”），不做数据驱动挑选。

## 3. 指标表对照（旧 → 新）

**保留并适配原表项**：目标存在检测、风险事件判定、距离估计、时延、状态稳定性、长时运行（原六项全部保留，报告方式不变：95% CI、配对比较、箱线图、瀑布图/CDF、时间线）。

**新增指标项**：

| 目标 | 主要指标 | 报告方式 |
|---|---|---|
| **多目标分离（RQ4）** | ≥2 目标帧占比、目标计数误差、MOTA/MOTP、两目标 y/x 差 MAE | 分几何（正后方/侧后方）× 档位，95% CI |
| **主目标选择（RQ5）** | 主目标=使用者识别正确率；目标关联质量（ID 切换/碎片数） | B2 vs B1 配对 + 效应量 |
| **负对照** | LD2410B vs LD2453 在同一场景“能否分离两人”的对比 | 定性 + 帧级占比对比 |

**统计口径（沿用原计划并补齐）**：报告样本量、剔除规则、缺失数据、CI、效应量；多重比较用 FDR；“每条件 30 次”改为功效/CI 精度论证（G*Power / Lakens 2022）；参与者/位置/试次当随机因子；真值标注报 Fleiss' kappa。

## 4. 需同步更新的两处

1. **冻结与一致性（P0）**：原计划“以 `firmware/include/config.h` 与 `privacy_state_machine.cpp` 为唯一事实来源”需扩展为“**LD2453 手册（版本号）+ 固件 + PC 客户端 + 解析器 + 雷达工程参数**”共同冻结；新增 `ld2453_parser_validation.md` 作为解析器一致性证据。
2. **论文结构 §3（系统与方法）**：新增“多目标目标关联 + 主目标选择 + 时序风险判定”三个子模块，替换原单目标“主距离选择/滤波”描述。
