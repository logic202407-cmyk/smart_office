## H1 — 多目标分离（LD2453 能力门槛）

```r
# 主指标1：≥2 目标帧占比（正后方 0.5m / 1.0m 档）
x <- sum(df$n_targets >= 2); n <- nrow(df)
binom.test(x, n)$conf.int              # Wilson/精确二项 95% CI
# 判据：CI 下限 ≥ 0.90 → 通过；否则 REVISE/NO-GO 复核

# 主指标2：两目标 y 差估计误差 MAE（对真值差）
df$y_diff <- diff_of_two_largest_y(df) # 取 y 最大的两个目标之差
mae <- mean(abs(df$y_diff - df$true_sep))
# 用 bootstrap 给 MAE 95% CI
```

## 多重比较与报告规范

1. 预注册**所有**要比较的假设；比较用 `adjust="fdr"`。
2. 不做“p<0.05 即结论”；以 CI 是否覆盖 0 / 非劣效界为准。
3. 报告实际 CI 宽度与效应量（Cohen's d / 差值），不报单均值。
4. 随机因子：person/position/trial；若模型不收敛，预注册降级方案（如去掉高阶随机效应）。
