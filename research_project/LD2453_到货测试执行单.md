# LD2453 到货测试执行单

## 目标与边界

本轮只验证传感器可行性：在固定安装条件下，LD2453 是否连续输出可区分的多目标坐标。
不把本轮结果写成“窥视意图识别”或最终性能结论。

## 到货前

- 让卖家确认：CH340 至雷达的 VCC 与 UART 逻辑均为 3.3 V；排线可用于 LD2453。
- 准备一台 Windows 电脑、卷尺、纸胶带、非金属支架或纸盒。
- 地面贴 50 cm 网格；记录显示器位置、雷达高度、朝向、环境中的风扇/窗帘。

## 到货后：先验证通讯

1. 将 LD2453 接到 CH340，**只接 3.3V，禁止接 5V**。
2. USB 接电脑，在设备管理器记录 CH340 的 COM 号。
3. 运行：

   ```powershell
   powershell.exe -ExecutionPolicy Bypass -File .\tools\ld2453_reader.ps1 -SelfTest
   powershell.exe -ExecutionPolicy Bypass -File .\tools\ld2453_reader.ps1 -Port COM7 -Output .\ei_experiments\raw\ld2453_pilot_r01.jsonl
   ```

4. COM7 只是一例，替换为设备管理器显示的真实端口。连续采集 30 秒并保存。

## 安装初值

- 雷达固定在显示器侧上方的非金属支架，不手持。
- 初始离地高度：1.5 m；相对显示器中心横向偏移：30–50 cm。
- 天线正面朝向显示器前方的人员活动区；前方保持开阔。
- 不以此安装值作为最终论文参数；它是第一轮可复现实验初值。

## 四个试次

每个试次 60 秒，开始和结束时口头报出试次编号并写入纸面记录。

| 编号 | 真实场景 | 通过条件 |
|---|---|---|
| E0 | 空场 | 无持续虚假目标 |
| U1 | 一人坐在终端前 | 持续至少一个合理目标 |
| UP1 | 坐姿使用者 + 后方静止者 | 在静止阶段出现两个空间分离目标 |
| UP2 | 后方者走入、停住、离开 | 轨迹和目标数随事件可解释变化 |

## 本轮输出

- 原始 JSONL；
- 安装照片与地面网格照片；
- 每个试次的真实起止时间、人员位置、异常干扰说明；
- `PASS / REVISE` 判定：若 UP1 连续 30 秒无法形成两个可解释目标，不进入 V2 打样。
